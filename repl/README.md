# Greenways control REPL

This is the isolated process-capable native Hara project for supported
`greenwaysd` and running Desktop control. The main Greenways OS Hara project is
unchanged and remains process-free.

See [`../docs/native-hara-control-repl.md`](../docs/native-hara-control-repl.md)
for setup, API examples, tests, troubleshooting, and credential revocation.
