# Greenways OS draft 0.1

Version 0.1 establishes the minimum confidence rail for a creative release:

1. a key-controlled identity uses a signed handle;
2. a project pins a workflow policy;
3. contributions and artifact versions receive signed claims;
4. bounded services return evidence and clearly typed quality results;
5. artists accept or reject proposed changes;
6. publication produces a portable checkpoint and evidence bundle; and
7. every signer keeps their own personal-chain inclusion record.

`verified-check`, `advisory`, and `sign-off` are intentionally different result
classes. None is a universal quality score or a declaration of legal title.
