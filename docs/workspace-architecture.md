# Workspace architecture

The product direction is now Foreman delivered and grounded by the Greenways
Fabric. Foreman is what a person installs, opens, and uses. The private
cross-platform Fabric Server, enrolled client host, person and AI-agent
identity, permissions, storage, and messaging remain invisible foundations
during ordinary use.

Foreman is the first application and the first end-to-end architecture proof.
It coordinates work, provider sessions, GitHub records, and agent-to-agent
messages across CLI, browser, Desktop, and API surfaces.

See [Greenways Fabric architecture](fabric-architecture.md) for the current
north-star design.

See [Greenways Fabric technology map](fabric-technology-map.md) for the internal
composition of Tahto semantics and authority, Hestia knowledge, Hara packages,
the client-only Hodos catalogue, and the Hoplite and Ignatius executors. Historia
is a migration and compatibility source for Hestia rather than a permanent peer
in that architecture. These implementation names do not become Foreman product
navigation or ordinary user terminology.

The earlier Chats-first daemon/Desktop architecture remains useful migration
and implementation evidence, but it no longer defines the product hierarchy or
the first application. Public publication and multi-channel delivery belong to
the separate Greenways Platform product.
